# 灾害预警插件（disaster_alert）

ClassBoard 插件：**地震预警** + **气象灾害预警**。地震来临时主岛与副岛会并成一条
**按预估烈度配色**的倒计时警报条（顶掉课程显示），平时预警信息显示在主岛加长片段与副岛上，
下拉面板给出详情。

> 预警信息来自公开接口，**仅供参考，请以官方发布为准**。

---

## 地震红色警报条（主岛 + 副岛融合，默认开启）

**地震来时，课程显示会被直接顶掉**——主岛与副岛并成一条**倒计时长条**：

```
四川长宁 · M6.0 · 预估烈度4.2 · 横波还有 12 秒 · 距震中 118km
```

- 底部进度条 = 剩余时间占比，随倒计时**平滑收缩**（~30fps 实时计算），到达后条跑空、
  文案变「横波已到达」；
- 条的颜色 = **预估烈度分档**（见下节）：小震蓝色、大震红色；
- **顶掉一切课表显示**：课程名、上课前蓝条倒计时、提醒条都让位（地震比上课要紧）；
- **不会被隐藏**：上课 / PPT 全屏 / WPS-Office 前台导致灵动岛收起时，会自动拉回屏幕顶部并保持显示；
- 结束后自动恢复课程显示，副岛重新出现（天气/媒体照旧）；
- 气象灾害**不使用**警报条（台风等长时间预警仍走"主岛片段 + 副岛"），避免整屏被长时间占满；
- 想关掉它：设置页「地震用红色警报条」取消勾选，即回到原来的"片段 + 副岛"显示。
- **小震不会长期占屏**：未达「展开门槛」的地震，警报条只占用 5 秒就自动交还课程显示
  （见下节「大震 vs 小震」），倒计时继续在主岛片段上展示。

---

## 大震 vs 小震：占用策略

警报条不会"一律长期占屏"——按预估烈度分两档处理：

| 情形 | 判定（默认） | 行为 |
|---|---|---|
| **大震** | 达到「展开门槛」（默认**红色档**，即预估烈度 >5） | 展开避险要诀；**一直顶掉课程显示**，必须**点击灵动岛 → 再点确认**才恢复上课 |
| **小震** | 未达门槛（蓝 / 黄 / 橙档） | 警报条**只占用 5 秒**（可调 0–60）→ 到点自动把课程显示还回去，**不需要确认**；倒计时继续在主岛加长片段上显示 |
| 小震设 0 | — | 小震**完全不占用**警报条（只走主岛片段 + 提醒条） |

- 小震的计时按**事件**计：同一事件升报（收到新一报）或来了新地震会**重新开始** 5 秒；
- 这样上课时小震只会短暂闪一下就让位，大震才会锁住屏幕要求确认。

---

## 避险要诀（第二层，向下多一排）

**红色的地震预警**会在警报条**下方再展开一排避险要诀**：

```
┌──────────────────────────────────────────────────────────────┐
│  四川长宁 · M6.5 · 预估烈度6.5 · 横波还有 18 秒 · 距震中 40km  │  ← 第一层（倒计时条）
├──────────────────────────────────────────────────────────────┤
│  !  伏地 · 遮挡 · 手抓牢 ｜ 远离窗玻璃与吊灯，勿乘电梯、勿跳楼  │  ← 第二层（避险要诀）
└──────────────────────────────────────────────────────────────┘
```

流程：

1. **前 60 秒**（可调）：两层并存——上面是倒计时条，下面是避险要诀；
2. **60 秒后**：第一层消失，窗口收成一层，**只留避险要诀并继续顶掉课程显示**
   （地震刚过也不要立刻讲课，先按要诀避险）；
3. **点击灵动岛** → 整条高亮、提示「点击确认，恢复上课显示」；
4. **再点一次** → 恢复上课状态；
5. **只点一次不管它** → **5 秒后自动退回第 2 步**（重新只显示要诀），
   误触不会解除警报，想恢复仍要点两次（可设为不超时）。

细节：

- 只有达到「展开门槛」（默认**红色档**，即预估烈度 >5）才展开要诀；
  小震既不展开要诀、也不长期占屏（只闪 5 秒，见上节）；
- 两层阶段点击**不响应**（地震还没过去，避免误触）；
- 待确认状态**只点一次不生效**：5 秒（可调，0=不超时）后自动退回要诀显示；
- 确认过的事件不再打扰；但**该地震发布新一报（升级）时会重新弹出**；
- 想关掉：设置页取消「地震时展开避险要诀」；想去掉二次确认：取消「点灵动岛 + 再点一次确认」；
- 要诀内容、展开门槛、第一层保持秒数都可在设置页改。

> 另外：**地震警报条优先于主程序的"上课倒计时演练"**——警报条显示期间点击演练会被拒绝；
> 若演练正在进行时来了地震，演练会被自动中止、警报条接管。

## 预估烈度配色（默认地震预警行业色标）

条的颜色按**预估烈度**分档——烈度代表你这里会不会晃、晃得多厉害，越危险越红：

| 档位 | 默认预估烈度 | 默认颜色 |
|---|---|---|
| 蓝 | ≤ 2.0 度 | `#4da3ff` |
| 黄 | 2.1 – 3.0 度 | `#ffd23f` |
| 橙 | 3.1 – 5.0 度 | `#ff9f0a` |
| 红 | > 5.0 度 | `#ff453a` |

三个**分界值**与四种**颜色**都可以在设置页自定义（颜色支持直接填 `#RRGGBB` 或点「选色…」）；
改动即时生效，警报条、主岛片段、副岛图标的颜色会一起跟着变。
设置页会实时显示当前分档，例如「蓝色 ≤2.0 ｜ 黄色 2.1 - 3.0 ｜ 橙色 3.1 - 5.0 ｜ 红色 >5.0」。

> 说明：这里刻意**没有**采用"倒计时越长越红"。那种做法会把远处的小震标成红色、
> 而近处的大震标成蓝色，与安全直觉相反。地震预警系统的标准做法就是按预估烈度分色。

## 预警分级展示（重要）

预警分两档，规则可在设置页调整：

| 档位 | 判定 | 展示策略 |
|---|---|---|
| **重要** | 类型命中「重要预警类型」（默认 **台风、地震、海啸**），或等级达到「重要等级门槛」（默认 **红色**） | 任何时间都显示（上课也显示）；**主岛 + 副岛一起占用**；**强制弹出**（PPT 全屏/灵动岛被隐藏也会弹回屏幕） |
| **一般** | 暴雨、高温、大雾、雷电等 | **只在课间与自习显示**（上课不打扰）；**不占用副岛**（把副岛留给天气/媒体）；安静提醒 |

- **自习**判定：当前正在上的课名里含"自习"（含晚自习）；课间/课后/假期也算自由时段。
- 想改判定：设置页「重要预警类型」填 `台风,地震,海啸,高温` 这样即可；「重要等级门槛」可选
  红色/橙色/黄色/不启用。
- 以上三条（强制弹出 / 只在课间与自习 / 不占副岛）都能单独关掉。

## 功能

- **地震预警**：实时监测地震预警信息，按你所在位置的**经纬度**计算震中距、本地烈度，
  以及**横波到达倒计时**（"横波还有 N 秒"）；到达后显示"横波已到 · 烈度X"。
- **气象灾害预警**：抓取所选省/市的气象预警（暴雨/雷电/大雾/暴雪…），按等级配色，
  橙/红等级会自动弹提醒条；**填写「城市」后只显示本市预警**（省内其他预警仅在下拉面板列出，
  不会误报成本地）。
- **长文本自动滚动**：主岛文案/片段/副岛文字放不下时会像跑马灯一样左右滚动，
  不再被硬裁掉半个字；宽度有上限，不会把岛撑得太长。
- **三种显示位**：
  | 位置 | 内容 |
  |---|---|
  | **地震警报条** | 主岛 + 副岛**融合成一条**红色倒计时条："震中 · 震级 · 烈度 · 横波还有 N 秒 · 距震中 Xkm"（仅地震） |
  | 主岛加长片段 | 等级色图标 + "横波还有 12 秒" / "暴雨橙色"（无警报条时使用） |
  | 副岛 | "M6.0 甘孜 · 烈度3.2 · 12s"（有预警时自动展开；无预警让位给天气插件） |
  | 下拉面板 | 震中/震级/深度/距离烈度/倒计时/第几报；气象预警列表；无预警时显示数据源状态 |
- **提醒条**：`api.notify` 弹出提醒，仅在"首次触发 / 等级升级 / 超过节流间隔"时提醒，不刷屏。
- **上课策略**：地震预警**上课也照常提醒**（安全优先）；气象**蓝/黄等级**上课期间静默，橙/红仍提醒。
- **演练模式（可指定震中）**：设置页选 **震中省份 → 城市 → 区县** 三级下拉，再调
  **震级**（3.0–9.0）与**震源深度**（1–60km），实时预览
  「震中 / 距你多少 km / 预估烈度多少 / 倒计时多少秒」。
  **到达倒计时不用手填**：选定震中后，倒计时直接由「震中距离 + 震源深度」查表算出
  （与真实预警同一套算法），点「开始演练」时发震时刻＝当下，横波就按这个真实秒数到达，
  保证演练结果不失真。预览还会提示「预估烈度低于阈值，演练不会有显示」这类情况。
- **全国城市下拉**：内置 **366 个地级行政区 + 2817 个区县**（含省 / 市 / 区县三级联动，
  可输入关键字搜索），选定城市后**自动填入经纬度**；城市同时决定气象预警的过滤范围，
  区县用于更精确的坐标与演练震中。「IP 自动定位」保留，会同时查询三个定位库并自动选中对应城市。
- **IP 定位（三源交叉）**：同时问三个定位库（pconline 国内库 / ipwho.is / ip-api），
  省份按多数投票、城市取国内库优先的结果、坐标取与城市一致的来源；
  三源结果不一致时会在设置页**明确提示**（不同 IP 库对中国 IP 的精度差异较大，
  必要时请手动填写城市与经纬度）。

## 数据源（均免 API Key）

| 用途 | 来源 | 说明 |
|---|---|---|
| 地震主源 | **ICL** 成都高新减灾研究所 `mobile-new.chinaeew.cn` | 秒级，含逐县烈度/倒计时 |
| 地震备源 | **Wolfx** `api.wolfx.jp`（四川/台网/福建/重庆） | ICL 连续失败 2 次后自动启用，四端点轮询（<2 次/秒） |
| 气象灾害 | **中央气象台** `www.nmc.cn/rest/findAlarm` | 按中文省名过滤；失败时回退全国列表 + 本地过滤 |

轮询：地震 5 秒（可配 3–30），气象 60 秒（可配 60–300）。所有请求 8 秒超时、失败指数退避、
断网时保留上次缓存照常显示。

## 倒计时算法

移植自参考项目 [EarthquakeWarningForClassIsLand](https://github.com/denglihong2007/EarthquakeWarningForClassIsLand)
的 `HuaniaEarthquakeCalculator.cs`（见 `quake_calc.py`）：

```
震中距   = Haversine(你的坐标, 震中坐标)，地球半径 6378.137 km
本地烈度 = 震级×1.363 + 2.941 − ln(震中距+7.0)×1.494   （负值取 0）
倒计时   = 按震源深度分 7 档（0-5、5-10…≥30 km）查表 + 线性插值；
           震中距 > 2181.449 km 时用斜率/截距线性外推
```

触发条件：本地烈度 > 阈值（默认 2.0）且横波尚未到达且到达时间在 120 秒内。

## 使用步骤

1. 重启 ClassBoard（新插件需重启加载）。
2. 打开设置 → 左侧 **⚠️ 灾害预警**。
3. **省份 → 城市**（下拉选择，可输入关键字搜索；区县可选）——选定后自动填入经纬度；
   **不选城市又不填坐标则无法计算地震倒计时**。也可点 **IP 自动定位** 自动选中。
4. 需要的话微调 **预估烈度 → 颜色分档**（三个分界值 + 四种颜色）。
5. 按需调整烈度阈值、最低等级、轮询间隔、提醒节流等。
6. 在「模拟演练」里选 **震中省份/城市/区县**、**震级**、**深度**，看下方预览确认效果，
   点 **开始演练**：主岛会立刻并成一条警报条并按倒计时收缩，约 20 秒后显示"横波已到达"。

## 设置项

| 项 | 默认 | 说明 |
|---|---|---|
| 省份 | 四川省 | 气象预警按省过滤（中文省名） |
| **城市** | 空 | **全国下拉（366 个地级行政区，可搜索）**；选定后自动填坐标；**填写后气象预警只显示本市** |
| **区县** | 空 | 可选；选定后坐标更精确（用于倒计时与演练震中） |
| 纬度 / 经度 | 空 | 倒计时必需；选城市自动填，也可手改；「IP 自动定位」保留 |
| 烈度阈值 | 2.0 | 低于该预估烈度不显示/不提醒 |
| **预估烈度分档** | 2.0 / 3.0 / 5.0 | 蓝→黄、黄→橙、橙→红 的三个分界（都可改） |
| **分档颜色** | 蓝黄橙红 | 四种颜色可自定义（填 `#RRGGBB` 或点「选色…」） |
| 气象最低等级 | 黄色 | 低于该等级不显示 |
| 提醒节流 | 30 秒 | 同一事件两次提醒的最小间隔 |
| 地震 / 气象轮询间隔 | 5 / 60 秒 | |
| 有预警时占用副岛 | 开 | 关则所有预警都不占副岛 |
| 上课期间静默气象低等级 | 开 | 地震/台风等重要预警不受影响 |
| 启用主岛提醒条 | 开 | |
| 无预警时面板显示状态 | 开 | 显示数据源可用性与坐标 |
| **重要预警强制弹出** | 开 | 上课 / PPT 全屏 / 灵动岛被隐藏时也强制弹回屏幕 |
| **重要预警类型** | 台风,地震,海啸 | 逗号分隔，可自行增删 |
| **重要等级门槛** | 红色 | 达到该等级也算重要（可设"不启用"只看类型） |
| **强制显示保持** | 60 秒 | 强制弹出后至少保持显示多久 |
| **一般预警只在课间与自习显示** | 开 | 关掉则上课也显示一般预警 |
| **一般预警不占用副岛** | 开 | 关掉则一般预警也占副岛 |
| **地震用红色警报条（主岛+副岛融合）** | 开 | 关掉则地震回到"主岛片段 + 副岛"显示 |
| **地震时展开「避险要诀」** | 开 | 警报条下方多一排；仅达到门槛的地震展开 |
| **要诀内容** | 伏地 · 遮挡 · 手抓牢… | 第二层显示的文字（可自定义） |
| **展开门槛** | 红色档 | 达到该预估烈度档才展开要诀（可选橙色档 / 不限制） |
| **第一层保持** | 60 秒 | 多少秒后第一层消失、只留避险要诀 |
| **点灵动岛 + 再点一次「确认」** | 开 | 关掉后第二层一次点击即恢复上课显示 |
| **只点一次后自动退回** | 5 秒 | 只点了一次不管它，多少秒后退回要诀显示（0=不超时） |
| **小震只占用** | 5 秒 | 未达门槛的小震，警报条只占用这么久就交还课程显示（0=完全不占用） |
| **演练震中 / 震级 / 深度** | 就近模拟 / 6.0 / 10km | 倒计时由这三者算出，不可手填 |
| **震中省份 / 城市 / 区县** | 就近模拟 | 演练震中（三级下拉，可搜索，366+2817 个选项） |
| **演练震级** | 6.0 级 | 3.0–9.0，步进 0.1 |
| **演练震源深度** | 10 km | 1–60 km |

## 文件

| 文件 | 作用 |
|---|---|
| `main.py` | 状态、生命周期、轮询调度、警报条与三个显示位 spec、提醒节流、演练、设置页 |
| `cities.py` | 全国省 / 地级市 / 区县 + 经纬度（自动生成，366 市 + 2817 区县） |
| `sources.py` | ICL / Wolfx / nmc.cn 请求与纯解析函数、退避状态机、去重合并 |
| `quake_calc.py` | Haversine、预估烈度、深度分档查表倒计时（含 8×101 查表数据）、可配置烈度分档 |
| `draw.py` | 主岛/副岛自绘（地震波纹、警告三角、脉冲点），支持自定义配色 |
| `config.json` | 插件配置（运行时生成） |
| `cache.json` | 事件缓存（断网时显示上次数据） |

> `cities.py` 由 `gen_cities.py` 从和风天气开源城市列表（qwd/LocationList, Apache-2.0）生成，
> 坐标已四舍五入到 4 位小数（约 11m），无需联网查询。

## 已知限制

- 副岛 / 主岛加长片段是**独占**资源：本插件优先级 11（高于媒体插件的 10）：有预警时媒体等内容会让位；
  地震警报条优先级 100，独占主岛并隐藏副岛。
- 地震警报条需要主程序支持 `add_island_banner`：插件会自动探测，老版主程序上会回退到
  "主岛片段 + 副岛"的显示方式（不会什么都不显示）。
- 完全关闭灵动岛时提醒条会静默失效，只能通过下拉面板查看状态。
- 若坐标未设置，只做气象预警，不做地震倒计时。
- 破坏性地震时公开接口可能拥塞，此时会退避重试并保留上次数据。
